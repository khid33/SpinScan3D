# SpinScan Firmware

ESP32 (WROOM-32D N4) とステッピングモーター (28BYJ-48 / ULN2003A) を使用した回転制御ファームウェアです。

## ハードウェア構成

### 接続図

| ESP32 Pin | ULN2003A Driver Pin | 備考 |
| :--- | :--- | :--- |
| GPIO 19 | IN1 | ステップ入力 1 |
| GPIO 18 | IN2 | ステップ入力 2 |
| GPIO 5 | IN3 | ステップ入力 3 |
| GPIO 17 | IN4 | ステップ入力 4 |
| 5V | VCC | モーター電源 (外部電源推奨) |
| GND | GND | 共通グランド |

**注意**: 28BYJ-48は消費電流が大きいため、ESP32の3.3V/5Vピンからではなく、外部5V電源からULN2003Aに給電することを強く推奨します。その際、ESP32のGNDと外部電源のGNDを必ず共通にしてください。

## API 仕様

HTTP GETリクエストを使用して制御します。

### 1. 初期位置に戻る (Home)
- **Endpoint**: `/home`
- **動作**: モーターを反時計回りに回転させ、リミットスイッチ（実装されている場合）または規定のステップ数分戻り、位置を0にリセットします。
- **実装上の注意**: 本サンプルコードでは物理スイッチがないため、単純に原点方向へ一定時間回転させ位置をリセットします。

### 2. 指定の角度に回る (Move)
- **Endpoint**: `/move?angle=[0-360]`
- **パラメータ**: `angle` (0から360の数値)
- **動作**: 指定された絶対角度（0-360度）までモーターを回転させます。

## セットアップ
1. Arduino IDEに `AccuStepper` ライブラリをインストールしてください。
2. `SpinScanFirmware.ino` の `ssid` と `password` をご自身の環境に合わせて変更してください。
3. ESP32に書き込んでください。
